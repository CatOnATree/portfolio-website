# Katriana Trinh's Portfolio

Personal portfolio website showcasing biomedical engineering projects, experience, and skills.

Live website: https://catonatree.github.io/portfolio-website/

## Preview locally

With Python installed, run this command from the project folder:

```sh
python serve.py
```

Open http://localhost:8080 in your browser.

## Publish updates

The site is hosted on GitHub Pages from the root of the `main` branch. After editing the site, run:

```sh
git add .
git commit -m "Update portfolio"
git push
```

GitHub Pages automatically publishes updates after each push. The `.nojekyll` file allows GitHub Pages to serve the static files directly.
